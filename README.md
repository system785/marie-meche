# Marie Meché — студия красоты в Санкт-Петербурге

Одностраничный многостраничный сайт студии красоты **Marie Meché**
(проспект Юрия Гагарина, 7, ЖК «Космос», Санкт-Петербург).

Сайт опубликован на GitHub Pages:

**https://system785.github.io/marie-meche/**

## Страницы

- `index.html` — главная
- `about.html` — о нас
- `services.html` — услуги
- `price.html` — прайс-лист
- `reviews.html` — отзывы
- `photo.html` — фото
- `blog.html` — блог (+ 4 статьи)
- `contacts.html` — контакты и карта
- `request.html` — запись онлайн
- `privacy.html` — политика конфиденциальности

## Технологии

- Статический HTML + CSS + ванильный JavaScript (без сборки и зависимостей)
- Адаптивная вёрстка (мобильные и десктоп)
- Анимации появления при скролле, галерея с лайтбоксом, фильтры, форма записи
- SEO: семантические заголовки, Open Graph, JSON-LD, `robots.txt`, `sitemap.xml`

## Структура

```
├── *.html            страницы сайта
├── css/style.css     стили
├── js/main.js        скрипты
└── img/              изображения и логотип
```

## Локальный запуск

```bash
python -m http.server 8137
# открыть http://127.0.0.1:8137/
```
